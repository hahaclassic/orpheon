# Orpheon

## Цель работы
Создать музыкальный сервис с открытыми лицензиями (*Creative Commons* и *Public Domain*), предоставляющий пользователям возможность легально и бесплатно слушать музыку, создавать плейлисты, делиться ими и находить самые популярные фрагменты треков.  

## Решаемая проблема / предоставляемая возможность
Большинство существующих сервисов ориентированы на коммерческую музыку и накладывают ограничения на использование треков в сторонних проектах.  
`Orpheon` предоставляет музыку с открытыми лицензиями, что делает её безопасной для применения в видео, играх, маркетинге и любых других проектах.

---

## Функциональные требования
1. Прослушивание треков (гость и пользователь).
2. Управление воспроизведением (пауза, перемотка, следующий/предыдущий трек).
3. Создание, редактирование и удаление пользовательских плейлистов.
4. Добавление плейлистов в избранное.
5. Отображение самых прослушиваемых моментов треков.
6. Отображение информации о лицензии каждого трека.
7. Администрирование: загрузка альбомов и треков.
8. Регистрация и авторизация пользователей.

## Примеры пользовательских сценариев

### 1. Прослушивание трека
Актор: Гость  
1. Открывает сайт.  
2. Выбирает трек или плейлист.  
3. Запускает воспроизведение.  
4. Перематывает или ставит на паузу.  

### 2. Создание плейлиста
Актор: Авторизованный пользователь  
1. Входит в систему.  
2. Выбирает «Создать плейлист».  
3. Задаёт название, описание и обложку.  
4. Добавляет треки.  
5. Устанавливает статус (публичный/приватный).  

### 3. Загрузка альбома
Актор: Администратор  
1. Авторизуется в панели администратора.  
2. Создаёт новый альбом.  
3. Добавляет название, жанры, дату выхода.  
4. Загружает аудиофайлы треков.  
5. Сохраняет изменения.
